Introdução ao Pentago

Pentago é um jogo de estratégia abstrato para dois jogadores.

  • Os jogadores se revezam para colocar uma peça em um tabuleiro 6x6.
  • Após colocar uma peça, o jogador rotaciona um dos quatro quadrantes 3x3 em 90 graus.
  • O objetivo é ser o primeiro a alinhar cinco de suas peças (na horizontal, vertical ou diagonal).

Objetivos do Projeto

Como Usuário

  • Jogar Pentago online em tempo real.
  • Desafiar amigos ou um oponente de computador.
  • Acompanhar o progresso em um ranking.
  • Comunicar-se com outros jogadores.

Como Desenvolvedor

  • Construir uma aplicação full-stack segura.
  • Implementar uma arquitetura cliente-servidor.
  • Usar WebSockets para interação em tempo real.
  • Ganhar experiência com tecnologias web modernas.

Tecnologias

  • Frontend: HTML5, CSS3, JavaScript (ES6+)
  • Backend: Node.js, Express.js
  • Banco de Dados: MongoDB com Mongoose
  • Comunicação em Tempo Real: Socket.IO
  • Autenticação: JSON Web Tokens (JWT)
  • Ambiente de Implantação: Servidor Online 24/7 (ex: VPS UFSC)

Funcionalidades Principais (1/2)

  • Autenticação de Usuários: Registro seguro e login baseado em JWT.
  • Matchmaking: Jogadores podem entrar em uma fila para serem pareados automaticamente com um oponente.
  • Jogabilidade em Tempo Real: Lógica de turnos Jogador vs. Jogador via WebSockets.
  • Jogador vs. Bot: Um oponente de IA simples para o modo de um jogador.

Funcionalidades Principais (2/2)

  • Espectador de Jogos & Chat: Assista a partidas em andamento e use o chat global ou do jogo.
  • Video-chamada com WebRTC: Funcionalidade de chamada de vídeo entre os jogadores.
  • Ranking: Sistema de classificação de jogadores baseado em pontuação.
  • Perfis de Usuário: Visualize perfis e históricos de jogos de outros jogadores.

Destaques do Código: Frontend

Tratando eventos WebSocket em client/public/js/game/game.js


// client/public/js/game/game.js

socket.on('piece_placed', (data) => {
  console.log('Peça colocada:', data);
  // Atualizar o estado do tabuleiro na UI
  updateBoardState(data.gameState.boardState);
  // Atualizar de quem é a vez
  updateTurnInfo(data.gameState.currentTurn);
  // Mudar a fase do jogo para rotação
  setGamePhase(data.gameState.gamePhase);
});

socket.on('quadrant_rotated', (data) => {
    console.log('Quadrante rotacionado:', data);
    // Animar a rotação do quadrante na UI
    animateQuadrantRotation(data.quadrant, data.direction, () => {
        // Atualizar o estado do tabuleiro e turno após a animação
        updateBoardState(data.gameState.boardState);
        updateTurnInfo(data.gameState.currentTurn);
        setGamePhase(data.gameState.gamePhase);
    });
});

Aspectos de Segurança (1/2)

  • Autenticação Robusta: Uso de JWT (JSON Web Tokens) para sessões stateless seguras, protegendo rotas da API e eventos WebSocket.
  • Segurança de Senhas: Senhas nunca são salvas em texto plano; utilizamos hashing forte com bcrypt e sal.
  • Validação de Entrada: Validação rigorosa no backend (Schema Validation) para garantir que apenas dados esperados sejam processados.

Aspectos de Segurança (2/2)

  • Prevenção XSS: Sanitização de inputs e escapamento no frontend contra injeção de scripts.
  • Rate Limiting: Limite de requisições por IP para mitigar ataques de força bruta e DoS.
  • Variáveis de Ambiente: Segredos (chaves, senhas) isolados em .env.
  • Proteção CSRF: Validação de origem/tokens contra falsificação de solicitações.
